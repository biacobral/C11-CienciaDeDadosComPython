Contém aulas, exercícios práticos e projetos de avaliação desenvolvidos
ao longo do semestre, com foco em análise e manipulação de dados.

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Estrutura

- `Aulas/` — notebooks das aulas teóricas e práticas
- `Exercicios/` — exercícios de fixação
- `Provas_Projetos/` — projetos de avaliação
